Player

Минималистичный музыкальный плеер для Android

Небольшое приложение для прослушивания музыки, которая хранится на самом телефоне: фоновое воспроизведение, эквалайзер, плейлисты, поиск.

Доступ к YouTube

По желанию приложение может показать список музыки, которую вы отметили как понравившуюся в YouTube Music. Для этого оно запрашивает доступ к вашему аккаунту Google только на чтение. Подключение необязательно — без него плеер полностью работоспособен.

Распространение

Приложение создано для личного использования и не публикуется в магазинах приложений.
